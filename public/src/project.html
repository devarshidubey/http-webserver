Project: HTTP Server

Hand-rolled.

hi yall so this is my http web server that I made over a whole month. It took 1500+ lines of code, shit ton of coffee and borderline mental breakdown over debugging nasty errors. Here’s what this baby does:

  • It is rfc compliant so ya'll know this gonna work on any modern system
  • I had a nightmare of a week to configure it to allow range requests from browser especially while serving video files: trust me don't blindly follow RFCs, look for the actual practices)
  • GZip compression enabled
  • ETag-based caching
  • supports dynamic content: data streaming, but only compatible with terminal commands like curl, (it generates a number every second on the fly))

Since this is a simple file server, i haven't implemented POST requests yet.

Under the Hood

The server has performed quite decently in stress tests, but there is still a large scope of improvement in latency, which im planning to do by integrating my in memory cache server with this.

So far I have ensured necessary optimizations at each level:

  • A custom dynamic buffer like C++ vector with amortized O(n) read/write.
  • Header parsing as raw bytes(no memcpy overhead)
  • Fast key-value mapping of headers

Security & Testing

I have taken care of most common security threats, tho you are welcome to give it a test drive.
